Run this on a real device

Camera and location access only work over HTTPS (or localhost), so pick one of these:

Open the hosted link on your phone

Open this page's URL in Safari or Chrome on the device. Tap Take a photo; the browser asks for camera, then location. On iOS, Share → Add to Home Screen launches it like an app.

Host the HTML file yourself

Save this file and put it on a free static host (GitHub Pages, Netlify, Vercel, Cloudflare Pages), then open that URL on your phone.

For local testing on the same Wi‑Fi, serve the folder and tunnel it to get an HTTPS URL:

npx serve .
npx localtunnel --port 3000   # or: ngrok http 3000

Wrap it in a native iOS app

Load the file in a WKWebView. Add these keys to Info.plist, and <input capture> plus navigator.geolocation will work inside the web view:

NSCameraUsageDescription
NSPhotoLibraryUsageDescription
NSLocationWhenInUseUsageDescription

Good to know

iOS strips EXIF from photos captured through the browser camera, so the Device location section is what records the precise position for those shots. EXIF GPS fields fill in only for originals chosen from the library.
